# Documentación de HEBRA

Esta carpeta registra el avance real del proyecto, para que cualquiera (o nosotros mismos
después de un descanso) pueda retomar sin perder el hilo.

- [`bitacora.md`](./bitacora.md) — registro cronológico: qué se hizo, cómo y por qué, sesión por sesión.
- [`arquitectura.md`](./arquitectura.md) — decisiones técnicas y por qué se tomaron (vive aquí, no en el README).
- [`pendientes.md`](./pendientes.md) — lo que falta, en progreso o planeado.

El `README.md` de la raíz es para **instalar y correr** el proyecto. Esta carpeta es para
**entender su evolución**. Cada vez que se complete un cambio relevante, se agrega una entrada
en `bitacora.md` (fecha + qué + cómo + por qué), y si cambia una decisión de arquitectura, se
actualiza `arquitectura.md`.
